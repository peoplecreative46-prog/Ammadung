# Folder Foto Kegiatan Proyek & Otomasi

Silakan masukkan foto-foto kegiatan atau tangkapan layar proyek Anda ke dalam folder ini.
Format file yang didukung: `.jpg`, `.jpeg`, `.png`, atau `.webp`.

Nama file default yang digunakan dalam sistem slide slider:
1. `01.jpg` - Dokumentasi/Screenshot Proyek 1
2. `02.jpg` - Dokumentasi/Screenshot Proyek 2
3. `03.jpg` - Dokumentasi/Screenshot Proyek 3
4. `04.jpg` - Dokumentasi/Screenshot Proyek 4

*(Anda dapat mengubah atau menambah file foto lainnya dan menyesuaikan src di file index.html pada bagian slider proyek).*
