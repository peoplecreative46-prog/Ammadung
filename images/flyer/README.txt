CARA MENAMBAHKAN FOTO FLYER
============================

1. Simpan foto flyer Anda di folder ini (images/flyer/).

2. Beri nama file sesuai urutan:
   01.jpg, 02.jpg, 03.jpg ... 09.jpg

   Format yang didukung: JPG, JPEG, PNG
   (jika PNG, ubah ekstensi di index.html atau rename ke .jpg)

3. Slot galeri saat ini: 9 foto (grid 3x3).
   Untuk menambah slot, salin blok <article class="ig-post"> di index.html
   dan sesuaikan nomor file (10.jpg, 11.jpg, dst.).

4. Foto yang belum ada akan tampil sebagai placeholder (+0, +1, ...)
   sampai file gambar ditambahkan.

5. Interaksi galeri:
   - Klik        → buka preview fullscreen
   - Double-click → animasi suka (♥)
   - Hover       → overlay gelap + ikon
   - Tombol suka tersimpan di browser (localStorage)
