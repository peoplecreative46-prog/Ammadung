# Portofolio Akademik & CV Modern - Ahmad, S.H.

Repository ini berisi source code untuk website portofolio interaktif profesional milik **Ahmad, S.H.**, seorang peneliti di bidang Hukum Keluarga Islam dan Akademisi. Website ini didesain menggunakan **Tailwind CSS** untuk antarmuka yang modern, responsif, dan elegan, serta dilengkapi fitur unduh resume otomatis ke format PDF.

## 🚀 Fitur Utama
- **Desain Modern & Interaktif:** Antarmuka responsif dengan skema warna gelap premium (*slate-dark theme*).
- **Tab Publikasi Ilmiah:** Menyortir secara rapi lebih dari 40 karya ilmiah ke dalam kategori (Scopus Q1, Sinta 2 & 3, Sinta 4 & 5, serta Buku/Lainnya).
- **Ekspor Ke PDF (Satu Klik):** Tombol interaktif untuk menyimpan dan mengunduh halaman CV langsung menjadi file PDF secara instan tanpa merusak layout.
- **Ringan & Cepat:** Dibuat menggunakan HTML5 vanilla, CSS Tailwind via CDN, dan JavaScript murni.

## 📂 Struktur File
1. `index.html` — Struktur markup utama, konten data diri, pendidikan, dan navigasi tab publikasi.
2. `script.js` — Logika interaktif perpindahan tab publikasi dan modul konfigurasi cetak `html2pdf.js`.
3. `README.md` — Dokumentasi proyek repository ini.

## 🌐 Cara Deploy ke GitHub Pages (Gratis)
1. Buat *Repository* baru di akun GitHub Anda (misal: `portofolio-ahmad`).
2. Upload ketiga file (`index.html`, `script.js`, `README.md`) ke dalam repository tersebut.
3. Masuk ke menu **Settings** > **Pages** di repository Anda.
4. Pada bagian **Build and deployment**, ubah Source menjadi **Deploy from a branch**.
5. Pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
6. Website portofolio profesional Anda akan langsung live dalam beberapa menit!
