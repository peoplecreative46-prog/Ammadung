# Portfolio Ahmad — Struktur Repositori

- `index.html` — halaman utama, berada langsung di root.
- `about.html` — halaman tambahan.
- `css/style.css` — seluruh styling, responsive layout, animasi, dan visual.
- `js/script.js` — interaksi menu mobile, counter, filter publikasi, reveal animation, cursor glow, dan print/PDF.
- `images/flyer/` — folder foto bahan flyer untuk galeri Instagram-style di halaman utama (nama file: `01.jpg`, `02.jpg`, …).

## Cara pakai
Upload seluruh isi folder `portfolio-ahmad` ke repository GitHub/hosting. Pastikan `index.html` tetap berada di root repository.

Fitur:
- Responsive desktop/tablet/mobile
- Sticky glass navigation
- Animated academic metrics
- Filter publikasi berdasarkan tahun
- Reveal-on-scroll
- Interactive cursor glow
- Print/PDF via browser
- Galeri flyer gaya Instagram (grid, hover, double-click suka, lightbox)
- Link Scopus, Google Scholar, ORCID, WhatsApp, LinkedIn, email
