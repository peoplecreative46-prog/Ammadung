# Direktori Sertifikat Ahmad

Folder ini digunakan untuk menyimpan seluruh dokumen sertifikat dan penghargaan milik Ahmad dalam format PDF atau gambar (PNG/JPG).

## Cara Menghubungkan Berkas:
1. Pindahkan file sertifikat fisik Anda ke dalam folder `certificates/` ini.
2. Pastikan nama file disesuaikan dengan atribut `href` pada halaman `index.html` (atau edit file `index.html` untuk menyesuaikan nama file).
   
Contoh nama berkas pendukung:
- `paradigma_13_apr_2026.pdf`
- `paradigma_20_apr_2026.pdf`
- `paradigma_15_jul_2026.pdf`
- `paradigma_03_okt_2025.pdf`
- `paradigma_24_apr_2025.pdf`
- `bedah_karya_blockchain_2025.pdf`
- `iglopas_30_apr_2026.pdf`
- `iglopas_08_mei_2026.pdf`
- `iglopas_09_des_2025.pdf`
- `iglopas_10_des_2025.pdf`
- `icocil_2026.pdf`
